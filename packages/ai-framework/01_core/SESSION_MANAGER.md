# Session Manager

Version: 0.1.0

## Purpose

The Session Manager maintains the current development session.

It keeps track of:

- Current Phase
- Current Component
- Current Task
- Completed Tasks
- Pending Tasks
- Session Notes

---

## Responsibilities

- Start a new session.
- Resume the previous session.
- Track completed work.
- Track pending work.
- Generate session summary.
- Pass session context to other modules.

---

## Input

- Current project status
- Previous session data
- User request

---

## Output

- Active session
- Updated task status
- Session summary
- Next recommended action

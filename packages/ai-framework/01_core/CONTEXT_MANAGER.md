Provide the AI with the correct project context before any execution begins.

1. Read INDEX.md
2. Load Core Documents
3. Detect Current Project Phase
4. Identify Relevant Files
5. Build AI Context
6. Pass Context to Session Manager

- Read Only

- Build Verified Context
- Follow Framework Constitution

- User Request
- Framework Documents
- Project Files

## Output

- Verified AI Context
- Recommended Next Action

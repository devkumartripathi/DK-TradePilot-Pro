## Development Rules

1. One Step at a Time
   - AI will complete only one verified step before moving to the next.

2. Verify Before Change
   - Every change must be verified before continuing.

3. One File = One Responsibility
   - Each file should have a single clear purpose.

4. Small and Modular
   - Keep files and modules small, reusable, and maintainable.

5. Local First
   - Development starts locally before deployment.

6. Self Documentation
   - Every completed task must update documentation automatically.

7. Command Library
   - Every new capability must be documented inside the Command Library.
Build a modular AI development framework that safely plans, develops, tests, reviews, and improves software through small, verified steps.

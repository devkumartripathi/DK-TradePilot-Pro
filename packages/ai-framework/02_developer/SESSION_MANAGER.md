# Session Manager AI

## Responsibility

Manage every development session from start to finish.

## Status

Draft
## Startup Sequence

1. Open Project
2. Resume Previous Session (if available)
3. Verify Project Structure
4. Read Constitution
5. Read Rules
6. Read Architecture
7. Read Session Workflow
8. Read Index
9. Detect Current Phase
10. Create Next Step
11. Wait for User Approval
## Decision Flow

IF project is not found
→ Ask user to select a project.

ELSE IF foundation is incomplete
→ Continue foundation work.

ELSE
→ Prepare only one next verified step.

WAIT for user approval before execution.
